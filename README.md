# Permission Audit

Bash-скрипт для поиска файлов с небезопасными правами доступа в Linux — тех, в которые может писать любой пользователь (world-writable).

Учебный проект. Делаю первые шаги в информационной безопасности.

## Что делает

Рекурсивно проверяет текущую папку и выводит все файлы, доступные на запись для категории «остальные».

## Как запустить

```bash
chmod +x audit.sh
./audit.sh
```

## Как устроен скрипт

- `find . -perm -o+w -type f` — ищет файлы, у которых у «остальных» есть право на запись.
- Выводит список найденных файлов между заголовками.

## Пример вывода

=== Аудит прав: ищу файлы, открытые на запись для всех ===
./opasnyy.txt
=== Проверка завершена ===


## Инструменты

Bash, find, права доступа Linux (chmod).
